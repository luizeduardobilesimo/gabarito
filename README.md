# Gabarito

Estudo de viabilidade de empreendimentos imobiliários — lote, regras urbanísticas, potencial e otimizador de produto, viabilidade financeira, garagem, pavimento tipo, sol e túnel de vento 3D.

- Gerar o app: `python build.py` → abre `test.html` no navegador.
- Guia completo da arquitetura e convenções: `CLAUDE.md`.
