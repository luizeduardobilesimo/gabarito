# Gabarito

Estudo de viabilidade de empreendimentos imobiliários — lote, regras urbanísticas, potencial e otimizador de produto, viabilidade financeira, garagem, pavimento tipo com cômodos, sol e túnel de vento 3D.

- Instalar: `npm install` e `npx playwright install chromium-headless-shell`.
- Rodar: `npm run dev` → http://localhost:5173 (ou `npm run bundle` e abrir `test.html`).
- Testar: `npm test` e `npm run screens -- all`.
- Arquitetura e convenções: `CLAUDE.md`. Roteiro e andamento: `PLANO.md`. Backend futuro: `docs/BACKEND.md`.
